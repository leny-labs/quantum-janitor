# Internationalisation (i18n)

Tout texte affiché passe par le système i18n. Le **français est la langue
source**, complète ; les autres langues sont des traductions partielles qui
**retombent sur le français** clé par clé.

Langues : `fr` (source), `en` (interface complète, noms de pièces / objets /
personnages / libellés, un dialogue d'exemple).

## Choisir la langue

1. `?lang=en` dans l'URL (mémorisé pour les visites suivantes) ;
2. sinon la préférence enregistrée (`localStorage["qj.lang"]`) ;
3. sinon le français.

Dans le jeu : bouton **« Langue : Français »** en haut à droite de l'écran titre
(le MENU ramène à l'écran titre). Changer de langue recharge la page : les
textes Phaser et les décors 3D sont figés en textures à leur création. La
sauvegarde, les flags et l'état Ink ne dépendent pas de la langue.

## Deux sortes de textes

### 1. Interface : `src/i18n/locales/<lang>.ts`

HUD, menus, aides, verbes par défaut, intro, écran de fin, textes peints dans
les décors 3D (`props.*`).

```ts
import { t, tl } from '../i18n';
t('hud.menu');                                  // « Menu »
t('hud.useOn', { item: 'Seau', target: 'B.O.B.' }); // interpolation {item} {target}
tl('title.slogans');                            // liste de textes
```

- `fr.ts` définit **toutes** les clés (et leur type) ; `en.ts` est un
  `PartialCatalog` : une clé absente s'affiche en français.
- Clés stables, regroupées par écran (`hud.*`, `inventory.*`, `intro.gary.*`…) ;
  TypeScript refuse une clé inconnue.
- Variables : `{nom}`, remplacées par `t(clé, { nom })`.
- Ajouter une langue : créer `src/i18n/locales/xx.ts` (`export const xx: PartialCatalog`),
  l'ajouter à `LANGS` et `UI` dans `src/i18n/index.ts`, et (facultatif)
  `content/locales/xx.yaml`.

### 2. Contenu narratif : `content/` + `content/locales/<lang>.yaml`

Le YAML des scènes / objets / personnages et les dialogues Ink restent écrits
**en clair, en français** : c'est la source, lisible et éditable sans détour.
Une traduction est un catalogue à deux sections :

```yaml
keys:   # textes du YAML : clé stable dérivée des ids → traduction
  scene.placard.title: Broom closet
  scene.placard.hotspot.seau.useLabel: Take
  item.fusible.name: Fuse 7B
  scene.placard.hotspot.seau.use.1: A janitor without a bucket…   # 2e action de la liste
  scene.placard.hotspot.bob.useItem.seau: Not your bucket.        # « bob: » est conservé
ink:    # textes Ink : texte source exact → traduction
  "Merci, B.O.B.": "Thanks, B.O.B."
  "« Merci, B.O.B. »": "“Thanks, B.O.B.”"
```

**Clés YAML** (calculées par `contentTexts()` dans `src/engine/localize.ts`,
à partir des `id` déjà utilisés pour les flags et les sorties) :

| Texte | Clé |
|---|---|
| nom / secteur de pièce | `scene.<scène>.title`, `scene.<scène>.sector` |
| hotspot | `scene.<scène>.hotspot.<id>.label`, `.useLabel` |
| réplique d'un verbe | `scene.<scène>.hotspot.<id>.look` (chaîne seule) ou `.look.<n>` (n-ième action d'une liste) ; idem `use`, `talk`, `useItemDefault`, `useItem.<objet>` |
| sortie | `scene.<scène>.exit.<id>.label`, `.lockedText[.<n>]` |
| entrée de pièce | `scene.<scène>.onEnter[.<n>]`, `.onFirstEnter[.<n>]` |
| décor 2D de repli | `scene.<scène>.art.<n>`, `scene.<scène>.hotspot.<id>.art.<n>` |
| objet | `item.<id>.name`, `.glyph`, `.look[.<n>]`, `.combine.<autre>[.<n>]` |
| personnage | `character.<id>.name`, `.portrait` |

Le préfixe de locuteur d'une réplique (`"bob: …"`) ne se traduit pas : la
traduction ne contient que le texte, le préfixe est conservé.

**Textes Ink** : l'Ink n'a pas d'identifiant de ligne ; la clé est le texte
source exact (comme gettext), sans le préfixe `id:` — répliques, choix
(`* [texte]`) et chaque alternative de `{~a|b|c}`. Le moteur traduit à
l'affichage (`DialogueRunner`) : le script Ink, ses tags (`# set: …`), ses
conditions et ses compteurs ne changent pas, donc ni le gameplay ni les
sauvegardes. Modifier une réplique française rend sa traduction orpheline :
l'outil le signale et la ligne s'affiche en français en attendant.

Le picto du verbe « utiliser » (main qui saisit, doigt qui appuie) est déduit
du libellé français **avant** traduction (`guessUseIcon`).

## Outils

| Commande | Rôle |
|---|---|
| `npm run i18n` | couverture par langue + erreurs (clé orpheline, variables `{…}` différentes, préfixe de locuteur répété) |
| `npm run i18n -- missing=en` | textes source encore non traduits, au format du catalogue (à coller puis traduire) |
| `npm run i18n -- keys` | toutes les clés YAML avec leur texte source |
| `npm run check:i18n` | détecteur de chaînes affichables en dur dans `src/` + `npm run i18n` (lancé par `npm run build`) |
| `npm run playthrough -- lang=en` | rejoue la solution complète avec le catalogue appliqué |

Le détecteur (`tools/i18n-hardcoded.ts`) lit les littéraux de `src/` (hors
`src/i18n/locales/`) et refuse ceux qui ressemblent à du texte : accents ou
typographie française, deux mots, mot capitalisé ou en capitales. Messages
développeur (`console.*`, `throw`) exclus ; faux positif technique : finir la
ligne par `// i18n-ignore`.
