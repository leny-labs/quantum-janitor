# Placeholders graphiques

Pour le MVP, tout le décor est dessiné à partir de formes simples décrites
dans les YAML de scène (`art:` → `rect`, `circle`, `text`). Aucun fichier
image n'est nécessaire pour jouer.

Ce dossier accueillera les illustrations définitives (une image de fond par
vue, portraits, icônes d'objets). Seul `bucket.svg` (favicon) est utilisé
pour l'instant.
